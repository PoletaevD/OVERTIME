# MERIDIAN field equipment

Broad matte ivory ceramic plates (#E6E2DA) overlap a recessed graphite chassis (#202528). Leave a dark seam between moving parts. Use satin metal only on exposed bearings, rails and sockets. Reserve cyan (#69E9ED) for powered surfaces and orange (#FF792B) for threats. Weak points use small gold apertures (#FFCF64).

Use bold italic TMP numerals for the primary reading, small upright capitals for labels and a dark keyline for text over combat. Keep the sight axis clear. The HUD concept illustrates spacing and material treatment. In-game labels follow the existing abilities.

| Signal | Treatment |
|---|---|
| Direct / weak / shield | Ivory number / larger gold number / steel blue BLOCKED |
| Explosion / slow / temporal | Orange burst / ice-blue status / violet number |
| Common / uncommon / rare / epic | Graphite housing / mint contact / blue ceramic plate / violet active socket |
| RESET / OVERRIDE / RECALL / BULLET TIME | Paired reverse chevron / violet segmented reverse / amber echo outline / mint elongated tick |
| Threat | Orange acquisition, red-orange locked, hot ivory discharge |
